# 규칙 발굴 비교와 재현 · 2026-10-26

추가 첨부 ZIP 비교는 [CPU 규칙 탐색 비교](cpu-rule-mining-20261026/README.md)를 참조합니다. 기존 외부모델 안의 제한된 단일 조건 보완과 실제 CPU·메모리 측정, 적용하지 않은 로직을 기록했습니다.


사용자가 제공한 `국가통계_가구생활조사_샘플.csv`와 `샘플.txt`를 참고로 검토했습니다. 원본 파일은 수정하지 않았습니다. 비교 코드는 참조 자료이며 배포 모델에 데이터명·컬럼명을 하드코딩하지 않습니다.

## 비교에서 확인한 차이

| 항목 | 첨부 예제 | 기존 IN-EDITAONE 및 적용 판단 |
|---|---|---|
| 실행 환경 | pandas·NumPy·scikit-learn의 CPU 코드, GPU 호출 없음 | 설치된 라이브러리 재사용. 새 모델·GPU·패키지 설치 없음 |
| 실제 실행 가능성 | `main()`에서 정의되지 않은 `load_data_data` 호출 | 예제를 그대로 실행·복사하지 않음 |
| 합계 탐색 | 수치 컬럼의 2~5항 조합 전수 조사. 설명의 6항 합계는 이 코드로 직접 탐색 불가 | 기존 제한된 beam 탐색 유지, 옵션 상한만 4→8. 기본값 3 유지 |
| 비율·제곱근 | 모든 분자·분모 조합 비교 | 제한된 학습 표본으로 분모 후보를 넓게 검사. 제곱근 분모는 선택 옵션 |
| 조건규칙 | 나이·가구원수·지역 컬럼 지정; 범주별 min/max를 규칙으로 출력 | 컬럼명에 의존하지 않는 기존 트리 유지. 문자열 숫자의 구간 인코딩 보강 |
| 검증 | 학습 자료의 R²·순도. `abs(R²−1)<1e−6`은 행별 오차 1e−6과 다름 | 기존 학습·허용오차 보정·선택 검증 분리 및 엄격한 숫자 변환 유지 |
| 최종 목적 | 규칙 문자열 출력, 위반 행 탐지는 구현되지 않음 | 저장 AST·허용오차로 전체 Target 탐지와 최종 에디팅 유지. 데모도 분석 표본 전체 탐지 |

첨부 CSV는 1,500행·55컬럼입니다. 실제 수치 컬럼 32개로 예제의 2~5항 합계 조합만 계산해도 6,602,752개입니다. 전수 탐색 시간을 현재 제한 탐색 시간과 같은 것으로 비교하지 않습니다. 첨부 프로그램 전체는 정상 종료 가능한 기준 구현이 아니므로 동일한 전체 실행 속도 배수를 제시하지 않습니다.

설명에 제시된 저축 식도 그대로 정답으로 쓰지 않았습니다. `월저축액 = 월총소득 − 월총지출`은 원본 1,500행 중 2행에만 맞고, 실제 주된 관계는 `월저축액 = 가처분소득 − 월총지출`입니다. 다른 수식도 반올림·일부 불일치가 있어 규칙 목록의 문구와 실제 데이터 검사를 구분합니다.

## 적용 구조

- 기존 `UNIFIED_EDITING_DISCOVER` / `MIXED_XAI_RULE_DISCOVER` 공통 엔진을 보강합니다. M90002 프리셋·M03003 저장 JOB·M04001 FLOW·퀵 에디팅은 기존 계약을 사용합니다.
- `maxFormulaFeatures`는 기본 3, 허용 1~8입니다. `formulaSqrtEnabled`는 기본 `false`; `a/sqrt(b)`에 학습된 배율·절편을 포함할 수 있습니다. 음수 제곱근·0 분모는 안전하게 계산 불가 처리합니다. 일반적인 임의 기호 연산 전체를 탐색하는 모델은 아닙니다.
- 학습 자료에서만 숫자 문자열을 판단합니다. 강한 숫자 비율, 최소 건수, 선행 0 코드 보호와 기존 범주 한도를 지킵니다. 원본 문자열·물리적 DB 타입을 바꾸지 않고 저장 AST에 안전한 숫자 해석을 표시합니다.
- 긴 합계는 고정 폭 후보 탐색으로 제한합니다. 근사 계수의 단순화는 학습 잔차 근거를 통과할 때만 저장 AST에 반영합니다. 표시만 정리하거나 작은 구성항을 무조건 제거하지 않습니다.
- 규칙 디스커버리는 최대 1만 행·100컬럼, 6항·제곱근 활성·수식 대상 12개입니다. 유형별 최대 5개 중 핵심 3개를 보여줍니다. 위반 후보·적용 행 수는 분석 표본 전체, 검증 일치율은 별도 선택 검증 구간입니다.
- 새 테이블·ALTER DDL·모델 등록 ID·라이브러리는 필요 없습니다. 기존 등록·저장 JOB을 덮어쓰지 않습니다. [옵션 적용 절차](../../INTEGRATED_EDITING_GUIDE.md#2026-10-26-수식-탐색-옵션)를 확인합니다.

## 실제 파일 비교 결과

같은 1,500행·55컬럼 문자열 원본, seed 42의 로컬 CPU 실행입니다. 조건·수식 건수는 엔진 전체 채택 건수이며 데모 화면에는 유형별 5개만 반환합니다. 실행 시간은 한 번 측정한 근사치로, 동시 테스트 부하가 있을 수 있습니다.

| 실행 구성 | 조건규칙 | 수식규칙 | 발굴 시간 |
|---|---:|---:|---:|
| 수정 전 데모: 수식 대상 12·3항 | 18 | 6 | 6.44초 |
| 수정 전 옵션 확대: 대상 32·4항 | 18 | 8 | 31.62초 |
| 개선 데모: 대상 12·6항·제곱근 | 21 | 11 | 15.50초 |
| 개선 확장: 대상 32·6항·제곱근 | 59 | 19 | 57.78초 |

검증 기준을 낮추지 않고 탐색 범위·발굴 가능한 관계를 넓힌 결과입니다. 처리 시간이 감소한 개선이라고 주장하지 않습니다. 단순 자료는 기존 기본값을 유지하고, 더 많은 관계가 필요한 자료에만 범위를 넓힐 수 있습니다.

규칙 건수 외에 해당 관계에서 실제로 어긋난 행을 찾는지도 검사했습니다. 다음은 알려진 산술 관계를 별도로 계산한 대조 결과로, 독립된 오류 정답 라벨은 아닙니다. 반올림 자료 비교의 0.051 허용치는 이 대조 검사에만 사용했고 제품의 허용오차에 하드코딩하지 않았습니다.

| 산술 관계 | 대조 불일치 | 개선 확장 규칙이 탐지한 대조 불일치 | 해당 관계의 추가 지적 |
|---|---:|---:|---:|
| 소득 4개 항목 합계 | 31 | 31 | 0 |
| 연간소득 = 월소득 × 12 | 24 | 24 | 0 |
| 가처분소득 = 총소득 − 세금 | 31 | 31 | 0 |
| 균등화소득 = 가처분소득 / √가구원수 | 21 | 21 | 0 |
| 지출 6개 항목 합계 | 28 | 28 | 0 |
| 저축 = 가처분소득 − 지출 | 25 | 25 | 0 |
| 주거비 부담 비율 | 20 | 2 | 0 |

일부 합계는 구성항을 결과 컬럼으로 둔 역방향 식으로 발견됩니다. 위반 행은 식만으로 오류 셀까지 확정한 것이 아니므로 실제 수정 위치는 검토해야 합니다. 주거비 비율은 채택된 조건 범위에만 적용되어 18행을 놓쳤습니다. 이 한계를 포함해 기록하며 모든 관계·위반을 찾았다고 안내하지 않습니다. 1인당 가처분소득은 반올림 범위 안의 자료여서 대조 불일치가 없었습니다.

6항 식의 복잡한 근사 계수가 정상 행 13개를 추가로 지적하는 중간 결과를 발견해 수정했습니다. 학습 잔차 근거를 통과하는 계수 묶음만 단순화하고, 같은 AST를 다시 보정·검증·탐지한 최종 결과는 위 표의 28개 탐지·추가 지적 0개입니다. 작은 구성항·상쇄·상관 대리변수·무관 자료·제곱근 정의역·검증 재학습 금지 검사를 함께 유지합니다.

비교 스크립트는 문자열 데이터·VARCHAR2 메타데이터로 실제 엔진을 실행하고 네트워크·Oracle·`.env` 로드를 차단합니다. 파일 SHA-256·패키지 버전·seed·옵션·실행시간·규칙 AST·분석 표본의 위반 건수를 보고서에 남기며 원본 데이터 행은 저장하지 않습니다. `old_demo`는 이전 옵션을 **현재 엔진**에서 비교하는 모드이며 과거 소스 실행을 대신하지 않습니다. 수정 전 실행 기록은 로컬 `.runtime/benchmark-baseline/`에 별도로 보존했습니다.

위반 후보는 확정 오류가 아닙니다. 동일 관계의 역방향 식이 여러 개일 수 있고, 대상·후보·규칙 한도 및 조건 범위 때문에 모든 관계나 위반을 찾는다고 보장하지 않습니다. 오프라인 SQL 호환 검사는 운영 Oracle의 권한·실행계획·PL/SQL 컴파일·실제 성능 검증을 대체하지 않습니다.

최종 검증은 전체 백엔드 498개 중 497개 통과(기존 도움말 로고 캐시 경로 검사 1개 실패 유지), 전체 프런트 208개 통과입니다. 실제 문자열 CSV 발굴·저장 AST·전체 SQL 탐지·후속 행의 위반·최종 수정 검증, 기존 등록·JOB 설정 보존, 모바일 상세와 위반 CSV를 포함합니다. Python/JS 문법·diff 검사를 마쳤고 로컬 서버 재시작 후 health·새 화면 200, 비로그인 세션 401을 확인했습니다.
